# Data directory

## Raw data

`raw/` contains the original semicolon-delimited sunspot datasets published by the World Data Center SILSO:

- `SN_d_tot_V2.0.csv`: daily total sunspot numbers
- `SN_m_tot_V2.0.csv`: monthly mean total sunspot numbers
- `SN_y_tot_V2.0.csv`: yearly mean total sunspot numbers

Source: [SILSO data files](https://www.sidc.be/SILSO/datafiles)

The raw files remain unchanged. In the daily file, a sunspot value of `-1` indicates that an observation is unavailable.

## Processed data

`processed/` contains the two-column `ds` and `y` datasets generated by the notebooks. Prophet expects:

- `ds`: observation timestamp
- `y`: total sunspot number

The notebooks recreate these files from the raw inputs, so every cleaning decision remains visible and reproducible.
